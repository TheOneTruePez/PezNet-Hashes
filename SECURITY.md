# Reporting a problem

Report it privately if:

- an installer's SHA-256 does not match its line in `bootstraps.txt`, or the
  installer is not listed;
- a PezNet server shows a root key fingerprint that is not in `roots.txt`;
- a line you checked before has changed or disappeared from this repository's
  history; or
- anything else here looks wrong.

Use **Report a vulnerability** on this repository's Security tab
(https://github.com/TheOneTruePez/PezNet-Hashes/security/advisories/new).
Please do not post about it publicly first.

Do not run an installer that does not match.
